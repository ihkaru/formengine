STANDAR OPERASIONAL PROSEDUR (SOP)

PELAYANAN PERMINTAAN DATA STATISTIK

DESA SEJEGI

1. INFORMASI UMUM
Nomor SOP : SOP/DESA-SJG/001/2025
Tanggal Berlaku : 1 Agustus 2025
Disahkan oleh : Kepala Desa Sejegi
Ruang Lingkup : Seluruh permintaan data statistik dari masyarakat dan OPD
2. TUJUAN
  • Memberikan pelayanan data yang cepat dan efisien.
  • Melindungi kerahasiaan data pribadi penduduk.
  • Mengoptimalkan penggunaan SDM dan waktu dengan proses minimal.
  • Memberikan data yang sudah siap pakai dalam bentuk digital.
3. LANDASAN HUKUM
  1. Undang-Undang Nomor 16 Tahun 1997 tentang Statistik.
  2. Undang-Undang Nomor 14 Tahun 2008 tentang Keterbukaan Informasi Publik.
  3. Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi.
  4. Peraturan Pemerintah Nomor 51 Tahun 1999 tentang Penyelenggaraan Statistik.
  5. Peraturan Presiden Nomor 39 Tahun 2019 tentang Satu Data Indonesia.
  6. Surat Edaran Kepala Badan Pusat Statistik Nomor B-061/BPS/2300/02/2021 tanggal 8 Februari 2021 tentang Program Desa Cinta Statistik (Desa Cantik).
4. DEFINISI DAN ISTILAH
  • Data Publikasi: Data dalam publikasi "Desa Sejegi Dalam Angka 2025".
  • Data Tabulasi: Data yang sudah dalam bentuk tabulasi tanpa identitas personal dari Google Sheet atau sumber lain.
  • Pemohon Internal: OPD, instansi pemerintah.
  • Pemohon Eksternal: Masyarakat umum, peneliti, mahasiswa, lembaga swasta.
5. DATA YANG TERSEDIA

A. DATA PUBLIKASI (DESA SEJEGI DALAM ANGKA 2025)

Tabel yang Tersedia:

  1. Tabel 1: Batas Wilayah Administrasi Desa Sejegi
  2. Tabel 2: Jumlah Penduduk Desa Sejegi Menurut Jenis Kelamin
  3. Tabel 3: Jumlah Kartu Keluarga Desa Sejegi
  4. Tabel 4: Jumlah Rumah di Desa Sejegi
  5. Tabel 5: Jumlah Orang Disabilitas Desa Sejegi
  6. Tabel 6: Jumlah Anak Putus Sekolah Desa Sejegi
  7. Tabel 7: Jumlah Bahan Utama Dinding Rumah Desa Sejegi
  8. Tabel 8: Jumlah Bahan Utama Lantai Terluas Rumah Desa Sejegi
  9. Tabel 9: Jumlah Bahan Utama Atap Terluas Rumah Desa Sejegi
  10. Tabel 10: Kepemilikan Fasilitas Buang Air Besar Sendiri Desa Sejegi
  11. Tabel 11: Cara Keluarga Membuang Sampah Rumah Tangga Desa Sejegi

B. DATA TABULASI LAIN YANG SIAP PAKAI

  • Data dari Google Sheet yang sudah ditabulasi tanpa identitas personal.
  • Data prodeskel yang sudah dalam bentuk agregat.

C. DATA YANG TIDAK DAPAT DIBERIKAN

  • Raw data dengan identitas personal.
  • Data yang mengandung nama dan alamat lengkap.
  • Data sensitif sesuai peraturan perundang-undangan.
6. PROSEDUR PELAYANAN

A. PENERIMAAN PERMINTAAN

  • Petugas: Perangkat Desa yang bertugas
  • Waktu: 2 menit
  • Kegiatan:
    1. Mendengarkan/membaca permintaan data.
    2. Mengidentifikasi jenis data yang diminta.
    3. Menentukan ketersediaan data.

B. PENGECEKAN DATA

  • Petugas: Perangkat Desa
  • Waktu: 2 menit
  • Kegiatan:

    Jika diminta data dari publikasi:

    • Cek nomor tabel yang diminta (Tabel 1-11).
    • Konfirmasi data tersedia.

    Jika diminta data tabulasi lain:

    • Cek ketersediaan di Google Sheet/data tabulasi siap pakai.
    • Pastikan tidak mengandung data pribadi.

C. PEMBERIAN DATA

Data TERSEDIA (5 menit)

  • Kegiatan:
    1. Ambil data yang diminta.
    2. Berikan dalam format digital (Email, WhatsApp, Flashdisk/Cloud).
    3. Selesai.

Data TIDAK TERSEDIA (1 menit)

  • Kegiatan:
    1. Jelaskan bahwa data tidak tersedia.
    2. Berikan alternatif data terdekat jika ada.
    3. Selesai.
7. PERSYARATAN MINIMAL

A. UNTUK SEMUA PEMOHON

  • Menyebutkan identitas (nama).
  • Menjelaskan data yang dibutuhkan (nomor tabel atau jenis data).
  • Menyebutkan keperluan (opsional, untuk membantu memberikan data yang tepat).

8. WAKTU PELAYANAN
Kondisi Data Waktu Pelayanan Keterangan
Data Publikasi (Tabel 1-11) 3 menit Langsung kirim
Data Tabulasi Lain 5 menit Cek dan kirim
Data Tidak Tersedia 1 menit Informasikan
Total maksimal pelayanan: 5 menit per permintaan
9. BIAYA PELAYANAN

SEMUA DATA GRATIS - Seluruhnya dalam bentuk soft file digital.

10. CARA PEMBERIAN DATA

A. VIA EMAIL

Kirim file PDF publikasi atau Excel tabulasi dengan Subjek: "Data [Nama Tabel/Jenis Data] - Desa Sejegi".

B. VIA WHATSAPP

Kirim foto tabel untuk data sederhana atau file untuk data lengkap.

C. VIA FLASHDISK/CLOUD STORAGE

Salin file ke media yang dibawa pemohon atau unggah ke Google Drive/cloud.

11. LANGKAH PROTEKSI DATA

A. CHECKLIST CEPAT (30 detik)

  • ✅ Tidak ada kolom nama
  • ✅ Tidak ada kolom alamat lengkap
  • ✅ Tidak ada kolom NIK
  • ✅ Data dalam bentuk agregat/total

B. DISCLAIMER SEDERHANA

Cantumkan di email atau sampaikan lisan: "Data ini untuk keperluan yang telah disebutkan dan tidak boleh disalahgunakan."

13. PANDUAN CEPAT UNTUK PETUGAS

A. DAFTAR DATA YANG SERING DIMINTA

Data Publikasi Populer: Tabel 2 (Jumlah Penduduk), Tabel 3 (Jumlah KK), Tabel 4 (Jumlah Rumah), Tabel 1 (Batas Wilayah).

Data Tabulasi Lain: Data penduduk per RT, data mata pencaharian, data usia penduduk (dari Google Sheet).

B. KALIMAT STANDAR PELAYANAN

  • Pembuka: "Data apa yang Bapak/Ibu butuhkan? Untuk keperluan apa?"
  • Konfirmasi: "Data ini tersedia, mau saya kirim via email atau WhatsApp? Ini data dari publikasi Desa Sejegi Dalam Angka 2025."
  • Jika tidak tersedia: "Maaf, data tersebut tidak tersedia. Yang ada adalah data [sebutkan alternatif]."
14. TIPS EFISIENSI MAKSIMAL

A. PERSIAPAN HARIAN (5 menit)

  • Pastikan file publikasi mudah diakses.
  • Cek koneksi internet untuk kirim email/WhatsApp.
  • Siapkan template email standar.

B. TEMPLATE EMAIL STANDAR

Subject: Data Statistik - Desa Sejegi

Yth. [Nama Pemohon]

Terlampir data yang diminta:
- [Nama tabel/data]
- Sumber: [Publikasi/Tabulasi Desa]

Data ini untuk keperluan yang telah disebutkan dan tidak boleh disalahgunakan.

Terima kasih.

Perangkat Desa Sejegi
15. MONITORING SEDERHANA

A. INDIKATOR SUKSES

  • Waktu pelayanan: Maksimal 5 menit per permintaan.
  • Tidak ada komplain terkait data salah atau data pribadi bocor.
  • Pemohon puas mendapatkan data yang dibutuhkan.

B. EVALUASI INFORMAL

  • Catat data apa yang paling sering diminta.
  • Identifikasi kendala yang sering muncul.
  • Pastikan file selalu update dan mudah diakses.
16. PENUTUP

SOP ini dirancang untuk memberikan pelayanan data statistik yang sangat cepat dan efisien. Dengan fokus pada data yang sudah tersedia dan proses minimal, pelayanan dapat diselesaikan dalam maksimal 5 menit per permintaan.
